# 友達のままじゃ ― デジタルシングルCD

終電前のバス停とホームを歌う2曲+ボーナストラック1曲を収めたデジタルシングルCD『友達のままじゃ』(NK-S002)を聴くための PWA。

公開 URL: https://tanabata-soft.github.io/t8k4cdrpv9/

## 使い方

- **短冊ジャケット**: 縦長の短冊型(8cmシングルの様式)。タップ/横スワイプで裏面に反転し、裏面は2曲のジャケットを結合した画像の上にライナーノートと曲目(番号・タイトル・ジャンル・長さ、表示専用)、バージョン表示を載せる。下のボタンは再生のみ。インストール方法への入口は、表ジャケットのボタン下の小リンク。
- **再生画面**: 歌詞が曲に合わせて流れる(自分でスクロールもでき、手を離して3秒で再生位置に戻る)。ジャケットをタップすると盤面(円盤)モード。前/次は端でループし、「前」は3秒より進んでいたら曲の先頭に戻る。右端のボタンで全曲リピートと1曲リピートを切り替える。トップに戻ると再生は止まる。バックグラウンド再生(Media Session)と画面スリープ防止に対応。
- ホーム画面に追加するとアプリとして使える。初回起動時に全曲の音源を端末へ一括ダウンロードするので、オフラインでも全曲聴ける。

収録曲: 1. 友達のままじゃ(3:00、表題曲) / 2. 終電のホーム(2:42、カップリング) / 3. 午前二時の境界線(2:57、ボーナストラック)。総再生時間 約9分。

## 構成

デジタルCDアルバム(NK-001)・デジタルシングルCD(NK-S001)と共通のエンジンを使い、形の違い(短冊型・ブックレットなし・裏面ノート)はデータ(`src/album/album.ts` の `layout: 'single'`)で切り替える。仕様は [docs/SINGLE.md](./docs/SINGLE.md)、制作手順は [docs/PRODUCTION.md](./docs/PRODUCTION.md)。

- `src/album/`: **このシングルのデータ一式(差し替え対象)**
  - `album.ts`: 題名・カタログ番号・形(layout)・裏面ノートの文面・奥付
  - `tracks.ts`: 曲目・解説(正本)
  - `sync.ts`: 歌詞の同期データ(字幕の歌詞に、文字起こしで照合した時刻を付けた生成物)
  - `media.ts`: 曲ごとの画像・音源の対応
  - `assets/`: 画像と音源(mp4)。`jacket.jpg`(短冊) / `back.jpg` / `bg.jpg`(テーマ色の色面) と `trackNN.jpg` / `trackNN.mp4` の固定スロット
- `src/logic.ts`: 純関数のロジック(時刻整形、曲順の循環、歌詞の現在行、ブックレット構成)
- `src/main.ts`: 画面と再生の制御

## 開発

```bash
npm ci
npm run dev          # 開発サーバー
npm run verify       # lint → test → build → check:dist → check:content
npx playwright install chromium && npm run test:e2e
npm run shots        # 主な画面の一括撮影(shots/all.png)
npm run build:preview # 作業確認用の単一 HTML(dist-preview/preview.html。音源は 96kbps 化して埋め込む)
```

ルールの詳細は [CLAUDE.md](./CLAUDE.md)、作業の状態は [docs/HANDOVER.md](./docs/HANDOVER.md) を参照。

## デバッグモード

ジャケット裏面パネルのバージョン表示(`デジタルシングルCD v1.0.0`)を続けて 5 回タップすると、左下に操作パネル(DEBUG)が出る。画面移動のショートカット用。もう一度 5 回タップするか、パネルの「終了」で消える。

## 素材・ライセンス

収録曲・歌詞は Google Drive の素材フォルダ「ちーカラオケ友達」の mp4 から制作。短冊ジャケットの主ビジュアルはライナーノートの世界観(雨のバス停)をもとに生成し、文字は後から合成した。コードは個人利用の範囲で公開している。
